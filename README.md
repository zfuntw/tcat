# 工作室形象網站 + 後台 CMS

前台是工作室風格的形象網站（首頁、關於、服務、作品集、文章專欄、聯絡表單），後台可以改網站設定、每個區塊的內容，也可以寫文章、管理作品。

- 技術：Node.js（≥18）+ Express + EJS，資料存在 `data/db.json`，不需要另外架資料庫
- 圖片上傳到 `public/uploads/`
- 文章編輯器用 Quill，由本機提供，不依賴外部 CDN

## 快速開始（不會寫程式也能用）

1. 到 https://nodejs.org 下載並安裝 **LTS 版本**，安裝過程一路按「下一步」
2. 下載這個專案並解壓縮（GitHub 頁面 → 綠色 Code 按鈕 → Download ZIP）
3. 雙擊啟動檔：
   - Windows：`start-windows.bat`
   - Mac：`start-mac.command`（第一次若被擋，請按右鍵 →「打開」）
4. 瀏覽器會自動打開後台 http://localhost:3000/admin
5. 啟動視窗必須保持開著，關掉視窗網站就會停止

## 快速開始（開發者）

```bash
npm install
npm start
```

- 前台：http://localhost:3000
- 後台：http://localhost:3000/admin
- 初始帳號密碼是 `admin` / `admin1234`。第一次登入會強制你改密碼。

## 環境變數

| 變數 | 說明 | 預設 |
|---|---|---|
| `PORT` | 網站埠號 | `3000` |
| `NODE_ENV` | 設成 `production` 時 Cookie 只走 HTTPS，靜態檔也會快取 | — |
| `SESSION_SECRET` | 登入 Session 加密金鑰。**正式環境必填**，沒設的話每次重啟都會登出 | 隨機 |
| `ADMIN_USER` / `ADMIN_PASSWORD` | 第一次啟動時建立的管理員帳密 | `admin` / `admin1234` |
| `DATA_DIR` | 資料檔的存放目錄 | `./data` |

## 前台頁面

| 網址 | 內容 |
|---|---|
| `/` | 首頁，依序是主視覺、關於、數字亮點、服務項目、精選作品、最新文章、CTA。每個區塊都能在後台開關 |
| `/about` | 關於我們，內容用所見即所得編輯器寫 |
| `/services` | 服務項目 |
| `/works`、`/works/:slug` | 作品集，前台會依分類自動產生篩選按鈕，另有作品內頁 |
| `/blog` | 文章列表，可依分類、標籤篩選、搜尋、分頁 |
| `/blog/:slug` | 文章內頁，有分享按鈕、上一篇／下一篇、相關文章 |
| `/contact` | 聯絡表單（有防灌機制），也可以嵌入 Google 地圖 |
| `/sitemap.xml`、`/robots.txt` | 自動產生 |

`/首頁` 會 301 轉址到 `/`，這樣沿用參考網站的網址結構也不會變成 404。

## 後台功能

| 選單 | 功能 |
|---|---|
| 儀表板 | 文章、草稿、作品、訊息數量，還有熱門文章瀏覽數 |
| 文章管理 | 新增／編輯／刪除文章，可以存草稿或排程發布（台灣時間）。內文可直接上傳圖片、嵌入 YouTube，封面、摘要、SEO 標題與描述都能設，草稿可以預覽 |
| 文章分類 | 分類的新增、改名、刪除 |
| 作品集／服務項目 | 新增、編輯、排序；作品可勾選要不要出現在首頁精選 |
| 首頁內容 | 每個區塊的標題、文字、圖片、按鈕，以及要不要顯示 |
| 關於我們／聯絡我們 | 頁面內容、Google 地圖 |
| 聯絡訊息 | 查看客戶留言，會標示未讀，可匯出 CSV（Excel 可以直接開） |
| 媒體庫 | 一次上傳多張圖片、複製圖片網址、刪除 |
| 網站設定 | 網站名稱、Logo、Favicon、配色、字體、導覽選單、聯絡資訊、社群連結、頁尾、SEO、分享圖、追蹤碼 |
| 帳號設定 | 改帳號與密碼、下載資料備份 |

### 追蹤碼（網站設定 → 追蹤碼）

- **GA4**：填入 `G-XXXX`，每一頁都會自動載入 gtag
- **GTM**：填入 `GTM-XXXX`。如果 GA4 已經放在 GTM 裡管理，上面的 GA4 欄位請留空，不然會重複計算
- **Meta Pixel**：填入 Pixel ID，每一頁會送 `PageView`
- 聯絡表單送出成功時，會同時送出 Meta `Lead`、GA4 `generate_lead`，以及 dataLayer 事件 `contact_form_submit`。事件送出後網址參數會被清掉，重新整理頁面不會重複算轉換
- 其他追蹤碼（例如 LINE Tag）可以貼在「自訂 `<head>` 程式碼」

## 部署注意事項

1. 伺服器上要保留 `data/` 和 `public/uploads/` 這兩個目錄。Render、Railway 這類平台要掛永久磁碟（Persistent Disk），不然每次重新部署內容都會消失
2. 一定要設定 `SESSION_SECRET` 和 `NODE_ENV=production`，並且走 HTTPS
3. 定期到「帳號設定 → 下載備份」備份內容。圖片請另外備份 `public/uploads/`

## 新增後台欄位

表單都定義在 `lib/forms.js`。在對應的區塊加一行欄位定義，後台就會自動出現輸入框，接著在 `views/site/` 的模板裡用 `home.欄位名稱` 或 `site.欄位名稱` 顯示就好。
